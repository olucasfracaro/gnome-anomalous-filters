# gnome-anomalous-filters

Extensão para o GNOME Shell feita para usuários com Tricromacia Anômala.

# Por que?

Sendo portador da **Deuteranomalia**, senti falta de uma extensão que incluísse esse outro tipo de Daltonismo.
Pesquisando na loja de extensões do GNOME, encontrei apenas extensões para pessoas com [dicromacia](https://pt.wikipedia.org/wiki/Daltonismo#Tipos_de_daltonismo), como por exemplo, a [Colorblind Filters](https://extensions.gnome.org/extension/5589/colorblind-filters/) do [G-dh](https://github.com/G-dh).

Os filtros dessas extensões são mais fortes, portanto, acabam sendo inviáveis para os tipos *-nomalia*

Com base nisso, resolvi criar a *gnome-anomalous-filters* para nos ajudar, os tricromatas anômalos 😁

# Instalação

## Código-fonte

Diretamente do repositório:

```bash
git clone https://github.com/olucasfracaro/gnome-anomalous-filters ~/.local/share/gnome-shell/extensions/
```

Depois, faça *logout* da sessão

```bash
gnome-session-quit --logout
```

> [!IMPORTANT]
> **NÃO FAÇA *LOGOUT* SE VOCÊ TEM ARQUIVOS NÃO SALVOS!**
